OUR LITTLE STORY — MOBILE-FRIENDLY EDITION

This package removes the Screenshots tab and its password gate completely, and improves the layout and navigation for phones and tablets.

WHAT CHANGED
- Removed the Screenshots navigation item, home card, page, password and screenshot upload/delete code.
- Added a fixed, thumb-friendly bottom navigation bar on phones.
- Added horizontally scrollable navigation on tablets.
- Improved mobile spacing, card grids, form sizing, touch targets, canvas sizing and modal scrolling.
- Preserved the existing Story, Memories, Journal, Doodle Together, Chat and Characters features.

INSTALLATION
1. Extract this ZIP.
2. Replace index.html, style.css and script.js in your existing website folder with these versions.
3. Keep using your existing Supabase project, database, storage bucket and data.
4. No new database migration is required for these changes.
5. Refresh the website. If old styles remain cached, hard-refresh with Ctrl + F5.

NOTES
- The existing Supabase credentials and project settings are preserved.
- The legacy screenshots table, if already created in Supabase, is left untouched; this update simply no longer uses it.
